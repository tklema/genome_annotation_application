# Genome Annotation Pipeline

Автоматизированный программный конвейер для мультимодальной аннотации геномов, реализованный на языке Nextflow. Конвейер выполняет следующие задачи: детекция повторяющихся элементов (Repeater2), обнаружение структурных перестроек с подтверждением результатов двумя независимыми инструментами (SyRI и EagleC2), разметка регионов топологически ассоциированных доменов (SpectralTAD), центромер (RepeatOBserver) и компартментов (HiC-SCA). Разметка обогащается информацией о повторяющихся элементах и генах. Проводится дополнительный анализ точек разрыва перестроек для выдвижения эволюционных гипотез. Полученные данные имеют визуальное представление (IGV и самописный визуализатор) и собраны в машиночитаемые форматы. Для воспроизведения вычислительного окружения используются Docker-образы.

## Общая схема работы

Конвейер принимает на вход:
- Два генома (FASTA)
- Гены для двух геномов (GFF/GTF)
- Hi-C карты (интра- и интергеномные в .mcool)
- Конфигурационный файл соответствия хромосом

На выходе получается:
- Подтвержденные структурные вариации
- Анализ точек разрыва с определением предкового генома
- TAD и A/B компартменты
- Предсказанные области центромер
- IGV-сессии для визуализации
- Изображения визуализатора перестроек

## Быстрый запуск

```bash
./nextflow run app.nf \
  --genome1 data/genome1.fasta \
  --genome2 data/genome2.fasta \
  --config data/chromosomes_config.txt \
  --mcool_intragenomic data/intra.mcool \
  --mcool_intergenomic data/inter.mcool \
  --genes1 data/genes1.gff3 \
  --genes2 data/genes2.gff3
```

## Входные данные

| Параметр | Описание | Формат |
|----------|----------|--------|
| `--genome1` | Первый геном (референсный) | FASTA |
| `--genome2` | Второй геном (сравниваемый) | FASTA |
| `--config` | Файл соответствия хромосом | txt |
| `--mcool_intragenomic` | Внутригеномная Hi-C карта | .mcool |
| `--mcool_intergenomic` | Межгеномная Hi-C карта | .mcool |
| `--genes1` | Аннотация генов для генома1 | GFF/GTF |
| `--genes2` | Аннотация генов для генома2 | GFF/GTF |

### Формат конфигурационного файла `--config`

Файл устанавливает соответствие между хромосомами двух геномов. Каждая строка имеет вид:

```хромосомы_из_первого_генома:хромосомы_из_второго_генома```,

где хромосомы перечисляются через запятую.

Пример конфигурационного файла:
```
chr1:chrom1
chr2,chr3:chrom2
chr4:chrom3,chrom4
chr5,chr6:chrom5,chrom6
```

## Контейнеризация

Конвейер полностью работает в Singularity-контейнерах, в которых установлены рабочие среды conda и скрипты/артефакты интегрируемых инструментов. Скрипты самого пайплайна лежат вне контейнера.

Nextflow автоматически скачивает образы с Docker Hub и кеширует их для последующих запусков. Поэтому, если образ на Docker Hub обновился, нужно очистить кэш Nextflow и заново запустить приложениеё.

| Процесс | Образ |
|---------|-------|
| SpectralTADAnalysis | `magnaid/genome-annotation-spectraltad-env:latest` |
| RunRepeatOBserver | `magnaid/genome-annotation-repeatobserver-env:latest` |
| EagleC | `magnaid/genome-annotation-eaglec-env:latest` |
| Остальные | `magnaid/genome-annotation-env:latest` |


## Этапы конвейера

| # | Название процесса | Что делает |
|---|-------------------|-------------|
| 1 | `Repeater2Genome1` / `Repeater2Genome2` | Поиск повторяющихся последовательностей в каждом геноме |
| 2 | `ExtractGenes1` / `ExtractGenes2` | Извлечение генов в единый формат |
| 3 | `CreateSyntheticGenomes` | Создание "синтетических" геномов по конфигурационному файлу |
| 4 | `SyRI` | Детекция структурных вариаций по геномной последовательностям |
| 5 | `MappingSyriResults` | Обратное преобразование синтетических геномов |
| 6 | `EagleC` | Детекция структурных вариаций по межгеномным Hi-C данным |
| 7 | `RunComparison` | Подтверждение результатов из SyRI данными EagleC |
| 8 | `AnnotateBreakpointsWithRepeats` | Анализ точек разрыва для эволюционных гипотез |
| 9 | `SpectralTADAnalysis` | Детекция TAD |
| 10 | `RunRepeatOBserver` | Предсказание центромер |
| 11 | `Compartments` | Определение A/B компартментов и обогащение информацией по тандемным повторам и генам |
| 12 | `PrepareIGVSessions` | Создание IGV-сессий |
| 13 | `Visualize` | Визуализация структурных перестроек |


## Выходные данные

| Файл/директория | Описание |
|-----------------|----------|
| `repeats1.bed`, `repeats2.bed` | Координаты повторов (формат: chr start end count) |
| `breakpoints_with_repeats.tsv` | Все перестройки с аннотацией повторов, перцентилями и выводом предка (ancestral_start / ancestral_end) |
| `eaglec.txt` | Результаты EagleC2 |
| `all_tads.bed` | TAD (BED + уровень иерархии) |
| `compartments_tandem_genes.txt` | A/B компартменты с количеством и покрытием генов и покрытием тандемных повторов |
| `SpeciesName_H0-AT_Centromere_histograms_summary.txt` | Центромеры (гистограммный метод) |
| `SpeciesName_H0-AT_Shannon_centromere_prediction_min.txt` | Центромеры (метод Шеннона) |
| `igv_sessions/` | IGV-сессии для каждого генома |
| `visualizations/` | Графические изображения перестроек |
